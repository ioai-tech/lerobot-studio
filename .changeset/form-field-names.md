Every form control the viewer renders now has an id and a label, so Chrome no longer reports "A form field element should have an id or name attribute" on a page that embeds the viewer (the sidebar's episode search and duration filters were reported). The `Input` and `Textarea` primitives give themselves a `useId` id when the caller passes none; the rows-per-page select and the subtask name field no longer use fixed ids, so two viewers on one page never share an id. No control has a `name` and the `Button` primitive defaults to `type="button"`, so a viewer mounted inside a host page's `<form>` neither adds fields to its submission nor submits it on a click. The two duration bounds are announced apart ("Minimum duration (s)", "Maximum duration (s)"; new message keys `sidebar.durationMin` and `sidebar.durationMax`), and the panel filter searches, the bulk task editor, the remote archive URL, the task dialog fields and the chart's action/state toggles have labels. A filter row is a toggle button that carries its state as `aria-pressed` (`true`, `false` or `mixed`); the box it draws is a picture, no longer a checkbox nested in the button.
