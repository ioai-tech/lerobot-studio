# 隐私

> **Language / 语言：** [English](/privacy) | [简体中文](./privacy)

## 网络请求与数据传输

打开本地文件或文件夹**不会**上传。打开远程 URL 时，浏览器会向该地址所在的服务器发送普通 HTTP 请求。该服务器可能依照自身政策记录 IP 地址、浏览器信息、来源地址或 URL 等请求信息。

`@ioai/lerobot-studio` 不包含分析脚本，也不会向 LeRobot Studio 服务发送使用数据、文件名或数据集元数据。如果你的应用添加了追踪，请在自己的隐私说明中披露。

---

## 浏览器存储

独立应用可能在浏览器中保存以下信息：

- 主题 / 语言 → `localStorage`
- 最近打开的标签和 URL → `localStorage`
- 浏览器允许时，已授权的文件/目录句柄 → IndexedDB（`lerobot-studio`）

这些存储不会保存数据集字节作为历史记录。句柄仍然需要权限，隐私浏览模式可能会禁用持久化。

清除浏览器的站点数据可以删除偏好设置、最近打开记录和保存的句柄；原始文件不会被删除。

---

## 网络行为一览

| 打开的内容               | 会发生什么                    |
| ------------------------ | ----------------------------- |
| 本地文件或文件夹         | 数据留在设备中                |
| 远程或样例 URL           | 请求发送至该 URL 的来源服务器 |
| 加入额外代理或认证的部署 | 由部署者负责披露              |

远程归档响应头：[CORS](./cors)。
