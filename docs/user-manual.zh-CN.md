# 使用指南

> **Language / 语言：** [English](/user-manual) | [简体中文](./user-manual)

本页介绍如何在独立应用 [lerobot.studio](https://lerobot.studio) 中查看和检查 LeRobot 数据集。

## 打开数据集

按数据所在的位置选择：

| 方式           | 适用场景                                 |
| -------------- | ---------------------------------------- |
| **本地文件夹** | 电脑中已经解压的 LeRobot 数据集          |
| **本地压缩包** | `.zip`、`.tar`、`.tar.gz`、`.tgz` 数据集 |
| **远程压缩包** | 上述压缩包的 HTTP(S) 地址                |

你也可以打开带有 `?url=...` 的分享链接。

本地文件夹和压缩包会在浏览器中处理，不会上传到云端。打开远程链接时，浏览器会向该链接所在的服务器请求数据。

### 最近打开

**打开**菜单会记录最近使用的数据集。如果此前授权过浏览器访问本地文件或文件夹，再次打开时浏览器可能会要求你重新授权。

## 浏览 Episode

在左侧栏选择 Episode。可以通过搜索和筛选找到某个任务，或按时长查看 Episode。

播放条可以：

- 播放或暂停；
- 拖动时间轴跳到指定帧；
- 通过按钮逐帧查看；
- 调整播放速度；
- 在顺序、随机和单集循环之间切换。

键盘快捷键：

| 按键                       | 操作                        |
| -------------------------- | --------------------------- |
| `Space`                    | 播放/暂停。编辑时暂停即标注 |
| `←` / `→`                  | 上一帧或下一帧              |
| `Shift` + `←` / `→`        | 前进或后退 10 帧            |
| `Cmd` / `Ctrl` + `←` / `→` | 前进或后退 5 帧             |
| `↑` / `↓`                  | 上一个或下一个 Episode      |
| `Home` / `End`             | 第一帧或最后一帧            |

## 查看数据

默认布局会让视频、图表和原始特征保持在同一帧。

- **视频 / 图像**显示相机数据。
- **图表**显示数值特征随时间的变化，可选择要绘制的特征。
- **原始数据**显示当前帧的源数据。
- 侧栏中的**分析**显示数据集概览、时长分布和任务分布。

你可以添加面板、向右或向下拆分布局，也可以关闭不需要的面板。

视频能否播放取决于浏览器和视频编解码器。即使视频无法播放，图表和原始数据通常仍可查看。

## 检查数据集

从应用菜单打开**数据集健康检查**，可检查常见格式问题，例如缺少元数据、Episode 数量不正确或文件缺失。检查结果可导出为 CSV。

## 编辑 Episode

对于完全支持的数据集（`v2.1` 和 `v3.0`），可以修改 Episode 的任务描述，批量选择 Episode，并在当前浏览器会话中删除或恢复 Episode。

这些修改只保留在当前浏览器会话中，直到你导出数据集。应用不会覆盖原始文件。

### 标注子任务

可写的 `v3.0` 可在 **编辑** 中标注。`v2.1` 可以查看已有的 `subtask_index`，但不能新增。

- 暂停（`Space`）会从上一段结束（或第 0 帧）标到当前帧。
- 播到 episode 结尾会停在当前集，并弹出最后一段空白。
- 点击进度条空白区可标注该段。
- 可拖拽边缘、双击改名、悬停删除。

只要存在子任务，时间轴就会显示彩色区间，不必打开编辑。官方未标注帧（`subtask_index = -1`）保持空白。缺少 `meta/subtasks.parquet` 时显示为 `Subtask N`。

`v3.0` 导出仅在勾选 **包含子任务** 时写入子任务。勾选后要求每个被导出帧都已标注，且不会写入 `-1`。额外的官方列（如 `task_index_high_level`）会保留。

已验证的 Hub 示例和下载命令见 [数据格式 — 官方 Hub 示例](./data-formats#official-hub-examples)。

`v2` 和 `v3` 系列中较新的 minor 版本可能以只读方式打开。`v2.0`、其他主版本和缺少版本信息的数据集不会打开。

### 裁剪 Episode

进入 **编辑 Episode**，在播放栏选择 **裁剪片段**。每条 Episode 可保留一个连续区间。拖动两端边界、输入帧号，或在播放头位置点击 **设为起点** / **设为终点**。帧号从 0 开始，起止帧都包含在保留范围内。**仅播放保留区间** 会在终点停止；**重置裁剪** 可恢复完整 Episode。

切换 Episode 会保留裁剪设置，刷新或关闭数据集后会清除。导出时只写入保留的数据行，重置帧号和时间戳，并同步裁剪子任务标注；标注覆盖检查仅针对保留的帧。数值统计重新计算；RGB/灰度图像统计按每个相机最多 100 帧均匀采样，包含保留区间的首尾帧。原始文件不会改变。

`v3.0` → `v3.0` 不勾选 **移除视频文件中的未使用片段（较慢）** 时快速导出：复制共享 MP4，将视频引用更新到保留区间；勾选后也会物理裁剪视频。其他版本组合会物理裁剪被编辑的 Episode。重编码需要浏览器支持相应编解码器，可能改变画质或文件大小。第一版支持恒定帧率的 RGB/灰度数据集；不匹配的时间戳、原始深度/TIFF 统计、缺失帧或编解码失败会明确报错，不会生成看似完整的数据集。

### 批量裁剪与动作区间建议

在 Episode 侧栏点击 **选择**，勾选 Episodes，再点击 **批量裁剪**。操作范围是当前筛选列表内选中的 Episodes。支持两种方式：

- **裁去固定时长**：从每条原始 Episode 的头尾各裁去指定秒数。重复计算不会累加裁剪；长度不足的 Episode 会跳过。
- **自动建议保留区间**：根据位置或夹爪状态检测运动，再保留动作前后的缓冲。两侧默认各 **3 秒**，可以分别调整。可选择状态特征、灵敏度和参与检测的维度；默认跳过已有裁剪，勾选覆盖后才会替换。

计算后检查各条建议的保留区间、裁去时长和状态。点击区间可在播放器中预览并调整帧边界。**返回批量裁剪** 只更新建议，点击 **应用选中区间** 后才影响导出。对话框内的 **撤销本次批量应用** 可恢复此前的裁剪，并保留后续修改；改变计算设置或开始下一次计算会清除这次撤销记录。未应用就关闭对话框，会丢弃建议。

检测使用数值状态的短时窗口、噪声阈值和保守边界余量，保留动作中间的停顿，不分析视频，也不识别任务语义。低频传感器漂移、极慢运动和机械臂回位可能无法与有效动作区分，需要结合实际录制数据检查灵敏度和维度选择。整段静止、数据缺失或无效、样本不足时显示无可靠建议；持续运动则保留整段。取消会丢弃待应用建议，正在进行的数据读取可能仍会在后台完成。

批量区间沿用手动裁剪的导出流程，包括子任务裁剪、统计重算和 **移除视频文件中的未使用片段（较慢）**。

## 导出数据集

独立应用可以导出受支持的 `v2.1` 和 `v3.0` 数据集。

- **ZIP** 导出适用于支持的浏览器。
- **文件夹**导出需要浏览器提供文件夹选择功能，通常在 Chromium 浏览器中可用。
- 可以导出为 LeRobot `v2.1` 或 `v3.0`。
- `v3.0` 有 **包含子任务** 选项，默认关闭。勾选后才会写入 `subtask_index` 和 `meta/subtasks.parquet`，并要求每个导出的 episode 都已完整标注。

导出的数据集会包含当前的 Episode 修改。React npm 包不包含导出引擎。

`v3.0` → `v3.0` 默认对仍被引用的共享 MP4 只复制一次，并保留每条 Episode 的视频时间区间；重写保留的 Parquet 数据行和数据划分范围，不重新编码视频。删除的 Episode 不再被数据集读取，但其画面可能仍在共享视频文件内；完全没有剩余引用的文件不会导出。需要实际裁去未使用画面时，勾选 **移除视频文件中的未使用片段（较慢）**。裁剪可能触发视频重编码并增大文件，因此删除 Episode 不保证 ZIP 更小。
