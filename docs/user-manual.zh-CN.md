# 使用指南

> **Language / 语言：** [English](/user-manual) | [简体中文](./user-manual)

本页介绍如何在独立应用 [lerobot.studio](https://lerobot.studio) 中查看和检查 LeRobot 数据集。

## 打开数据集

按数据所在的位置选择：

| 方式           | 适用场景                                 |
| -------------- | ---------------------------------------- |
| **本地文件夹** | 电脑中已经解压的 LeRobot 数据集          |
| **本地压缩包** | `.zip`、`.tar`、`.tar.gz`、`.tgz` 数据集 |
| **远程压缩包** | 上述压缩包的 HTTP(S) 地址                |

你也可以打开带有 `?url=...` 的分享链接。

本地文件夹和压缩包会在浏览器中处理，不会上传到云端。打开远程链接时，浏览器会向该链接所在的服务器请求数据。

### 最近打开

**打开**菜单会记录最近使用的数据集。如果此前授权过浏览器访问本地文件或文件夹，再次打开时浏览器可能会要求你重新授权。

## 浏览 Episode

在左侧栏选择 Episode。可以通过搜索和筛选找到某个任务，或按时长查看 Episode。

播放条可以：

- 播放或暂停；
- 拖动时间轴跳到指定帧；
- 通过按钮逐帧查看；
- 调整播放速度；
- 在顺序、随机和单集循环之间切换。

键盘快捷键：

| 按键                       | 操作                   |
| -------------------------- | ---------------------- |
| `Space`                    | 播放或暂停             |
| `←` / `→`                  | 上一帧或下一帧         |
| `Shift` + `←` / `→`        | 前进或后退 10 帧       |
| `Cmd` / `Ctrl` + `←` / `→` | 前进或后退 5 帧        |
| `↑` / `↓`                  | 上一个或下一个 Episode |
| `Home` / `End`             | 第一帧或最后一帧       |
| `Q`                        | 标记子任务开始         |
| `R`                        | 标记子任务结束         |

## 查看数据

默认布局会让视频、图表和原始特征保持在同一帧。

- **视频 / 图像**显示相机数据。
- **图表**显示数值特征随时间的变化，可选择要绘制的特征。
- **原始数据**显示当前帧的源数据。
- 侧栏中的**分析**显示数据集概览、时长分布和任务分布。

你可以添加面板、向右或向下拆分布局，也可以关闭不需要的面板。

视频能否播放取决于浏览器和视频编解码器。即使视频无法播放，图表和原始数据通常仍可查看。

## 检查数据集

从应用菜单打开**数据集健康检查**，可检查常见格式问题，例如缺少元数据、Episode 数量不正确或文件缺失。检查结果可导出为 CSV。

## 编辑 Episode

对于完全支持的数据集（`v2.1` 和 `v3.0`），可以修改 Episode 的任务描述，批量选择 Episode，并在当前浏览器会话中删除或恢复 Episode。

这些修改只保留在当前浏览器会话中，直到你导出数据集。应用不会覆盖原始文件。

### 标注子任务

可写的 `v3.0` 数据集可以用帧范围标注子任务。`v2.1` 可以查看已有的 `subtask_index`（包括 PI 风格的 `metadata.subtask_*` 列），但不能新增标注。**开始** / **结束**（`Q` / `R`）只在可写的 `v3.0` 上出现。

1. 在子任务的第一帧按下 **开始** 或 `Q`。
2. 播放或跳转到最后一帧，再按 **结束** 或 `R`。
3. 在弹出的对话框中输入描述。已有标签可作为快捷选项。
4. 继续下一段。下一段的开始默认是上一段结束的下一帧。

时间轴会显示彩色区间。侧栏列出当前 Episode 的分段和 `已标注/总帧数` 覆盖。官方未标注帧（`subtask_index = -1`）显示为 **未标注**，不会出现在分段列表中。缺少 `meta/subtasks.parquet` 时，索引显示为 `Subtask N`。

导出为 `v3.0` 时，每个被导出 Episode 的每一帧都必须有子任务。未覆盖的帧会阻止导出；应用不会写入 `subtask_index = -1`。额外的官方列（如 `task_index_high_level`）会保留。

已验证的 Hub 示例和下载命令见 [数据格式 — 官方 Hub 示例](./data-formats#official-hub-examples)。

`v2` 和 `v3` 系列中较新的 minor 版本可能以只读方式打开。`v2.0`、其他主版本和缺少版本信息的数据集不会打开。

## 导出数据集

独立应用可以导出受支持的 `v2.1` 和 `v3.0` 数据集。

- **ZIP** 导出适用于支持的浏览器。
- **文件夹**导出需要浏览器提供文件夹选择功能，通常在 Chromium 浏览器中可用。
- 可以导出为 LeRobot `v2.1` 或 `v3.0`。

导出的数据集会包含当前的 Episode 修改。React npm 包不包含导出引擎。
