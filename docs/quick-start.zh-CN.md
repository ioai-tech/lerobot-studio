# 快速开始

> **Language / 语言：** [English](/quick-start) | [简体中文](./quick-start)

本页介绍如何使用独立应用快速查看数据集。如果需要在 React 应用中嵌入查看器，请阅读 [嵌入指南](./embedding)。

## 打开应用

访问 [lerobot.studio](https://lerobot.studio)，无需安装。

选择以下任一方式：

1. **本地文件夹**：适用于已经解压的数据集。
2. **本地压缩包**：支持 `.zip`、`.tar`、`.tar.gz` 和 `.tgz`。
3. **远程压缩包**：填写 HTTP(S) 链接。

本地文件会在浏览器中处理，不会上传到云端。打开远程压缩包时，浏览器会从你提供的链接请求数据。

## 查看数据集

打开数据集后：

1. 在左侧栏选择 Episode。
2. 使用播放控制条切换帧。
3. 对照查看同一帧的视频、图表和原始数据。
4. 如果需要检查常见格式问题，打开**数据集健康检查**。

编辑、导出、快捷键和面板布局的详细说明见 [使用指南](./user-manual)。

## 远程压缩包

对于较大的远程数据集，文件服务器应支持跨域请求和 HTTP 范围请求。详见 [CORS 与 HTTP Range](./cors)。
